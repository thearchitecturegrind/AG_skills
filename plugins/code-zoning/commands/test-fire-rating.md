description: Checks the required hourly rating for an element.
argument-hint: [the element, building type, and the code table]
---
Check the required hourly fire-resistance rating for a building element (for example a wall, floor, shaft, or structural frame). Input: $ARGUMENTS
If $ARGUMENTS is empty, ask for: element, construction type, use group, sprinkler status, separation distance if relevant, and the rating table or text.
Use only table values or code text the user pastes, or ones you fetch from a current official source and cite with URL and date; never use values from memory. If you cannot verify a value, label it unverified.
Steps:
1. identify the table row and column for the element
2. note footnotes and sprinkler reductions, each with its condition
3. state the required rating in hours with the source
4. compare to the drawn or specified assembly rating and its listing reference, if supplied
5. list openings and penetrations that need protection
Show every calculation line by line so the reviewer can follow it.
Result: required rating, provided rating, and pass, fail, marginal, or cannot-tell, with the numbers behind it, the source of each limit, and any missing input.
Never recommend a specific listed assembly unless the user supplied it.
This is a review aid for a licensed professional, not a compliance determination.

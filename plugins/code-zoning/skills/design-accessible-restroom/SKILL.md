# Design Accessible Restroom
Produces a dimensioned layout approach and a clearance overlap diagram described in text or ASCII, with each dimension tied to a source. A good result shows which clearances share floor area and where a door swing intrudes.
## Ask first
1. Paste the accessibility standard text for the turning space, fixtures, and door clearances, or I will fetch from the adopted standard. [fetch and cite]
2. Room type: single-user, or multi-user with how many fixtures? Interior dimensions available? [required]
3. Door type and swing, and any fixed constraints such as shafts or walls. [unknown]
## Core rules
- Clearances may overlap only where the standard permits; asking is cheaper than redrawing, so confirm each overlap against the text.
- Draw door swings last, because they often steal the turning space.
- Use dimensions from the supplied or fetched text only; none from memory.
- Show the arithmetic for room size so a reviewer can follow it.
- Layouts are drafts for a licensed professional to verify, not a compliance determination.
## Workflow
1. Collect the required clearances and note any that allow overlap.
2. Place turning space first, then the water closet clearance, lavatory clearance, and grab bar walls.
3. Test overlaps and the door swing against the room's inside dimensions.
4. Adjust fixtures or the door until each clearance holds; note alternatives.
5. Output: layout description with dimensions | clearance table (item, required, provided, source) | issues.
## If your setup is different
- Room is too small: give the smallest change that fixes it, such as enlarging or changing the door to out-swing, with the tradeoff.
- Alteration to an existing room: ask which infeasibility provisions the user can cite and verify.
- Different accessibility standard: follow the same sequence with that standard's text.

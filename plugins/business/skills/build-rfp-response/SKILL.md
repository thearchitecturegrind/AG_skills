# Build RFP Response

Produce a compliant, scoring-aware first draft so the user spends their time on content only they can supply.

## Ask first
1. Upload the full RFP including addenda.
2. Your firm's relevant projects, team bios, and any boilerplate to reuse.
3. Go/no-go: do you want a quick fit assessment first? [default: yes, short]

## Core rules
- Build the compliance checklist first (deadline, format, page limits, required forms, submission method). A non-compliant response gets thrown out.
- Match the structure to the evaluation criteria and their weights.
- Use only experience, credentials, and numbers the user gave you. Never invent projects, awards, or staff.
- Leave clearly marked placeholders where information is missing.

## Workflow
1. Checklist of requirements with source page references.
2. Fit assessment: strengths, gaps, and risks in a few lines.
3. Outline mapped to evaluation criteria.
4. Draft sections: understanding of the project, approach, team, relevant experience, schedule.
5. List of open items the user must supply, plus submission-day checks.

## If your setup is different
- No firm materials provided: draft structure and prompts only.
- Short RFQ: collapse to qualifications and a project list.

## Check the result
- Every RFP requirement appears in the checklist.
- No fabricated facts; all gaps are placeholders.
- Page and format limits are respected.

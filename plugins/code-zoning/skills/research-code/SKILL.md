# Research Code

Answer code questions by finding the adopted text, not by recalling it. Codes change and local amendments are common, so memory is the wrong source.

## Ask first
1. Jurisdiction (city/county/state) and project address if available.
2. Occupancy/use, construction type, building size, and whether it's new, addition, or renovation.
3. The specific question.

## Core rules
- Identify the adopted edition and local amendments before answering. Say which you found and where.
- Cite section numbers only from a source you actually read this session. If you can't verify, say "I couldn't confirm this" instead of citing from memory.
- Give the answer, the conditions it depends on, and the exceptions that might change it.
- You are not the code official. End with who to confirm with (plan reviewer, fire marshal, zoning administrator).

## Workflow
1. Find the adopting ordinance or state code page; note edition and amendment date.
2. Locate the relevant chapter(s); read the actual text.
3. Check exceptions, referenced standards, and local amendments.
4. Report: answer in a sentence, then the reasoning, citations, assumptions, and open questions.

## If your setup is different
- Source behind a paywall or not reachable: say so, give what can be found (e.g. a summary page), and mark it unverified.
- Unknown jurisdiction: ask; don't default to a model code.

## Check the result
- Every requirement has a verified citation or an "unverified" label.
- Edition and amendments are stated.
- Assumptions about the project are listed.

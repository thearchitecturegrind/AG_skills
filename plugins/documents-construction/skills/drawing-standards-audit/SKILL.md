# Drawing Standards Audit
Produces a findings list on how readable and consistent a drawing set is, against the firm's standard. A good result gives sheet-level fixes, not general advice.
## Ask first
1. Do you have a firm or client drawing standard? [ask; if none, use plain-language readability checks]
2. Which sheets? [a sample of each discipline]
3. What print size will it be read at? [ask; legibility depends on it]
## Core rules
- Judge against the user's standard; where none exists, label checks as practice, not rules.
- Check at print size; text that reads on a monitor can fail on paper.
- Cite sheet and area for each finding.
- Accessibility and code symbols are not judged here; refer to the licensed professional.
## Workflow
1. Gather the standard and sample sheets; render pages at print scale.
2. Check titles, numbering, north arrows, scale bars, and revision blocks.
3. Check line weights and hierarchy, text sizes, and overlapping text.
4. Check consistency: abbreviations, symbol use, tag styles, callout formats.
5. Check cross-references land on real sheets.
6. Output: findings table (sheet, area, issue, suggested fix, priority) and a pattern summary.
## If your setup is different
- If graphics are rasterized, say measurements are approximate.
- If the firm uses a national standard, ask which one and use the user's copy.
- If only one sheet is given, note that patterns cannot be judged.
## Check the result
- [ ] Findings cite sheet and location.
- [ ] The standard used is named.
- [ ] Priority is stated for each finding.

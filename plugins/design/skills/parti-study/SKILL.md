# Parti Study
Names the single organizing idea of a scheme, then tests whether the plan, section, and details follow it. A good result states the parti in a sentence, shows where it holds, and shows where it is abandoned.

## Ask first
1. What drawings or description do you have? [if only text, the study tests the idea's logic, not its drawing]
2. Does the author state a concept? [if yes, quote it; if no, I will propose one and mark it "inferred"]
3. What matters most: site, programme, structure, light, or experience? [assume the first one the author mentions]

## Core rules
- A parti is one move that organizes many decisions, such as a spine, a courtyard, a stack, or a wrapper; if it needs a paragraph, it is not one yet.
- State the parti as a sentence of the form "The building is a ... that ... so that ...".
- Test it at several scales and drawings; many concepts are strong in the diagram and absent in the section.
- Look for the rival parti the drawings could equally support; ambiguity is a finding.
- Distinguish a concept that is expressive from one that solves a problem; both are valid, but they are tested differently.

## Workflow
1. Draft up to three candidate parti statements from the material.
2. Choose the strongest and justify it with evidence.
3. Test it against site response, programme organization, circulation, structure, and section.
4. Record where it holds and where it breaks, citing the drawing.
5. Suggest how to strengthen it or how to change the concept to match the plan.
6. Output: Parti statement, Alternatives, Test table (aspect, holds or breaks, evidence), Strengthening moves.

## If your setup is different
- Urban infill: test the parti against the context before the interior.
- Student project: add the question "what would you remove to make the idea clearer".
- Multiple buildings: state the parti for the group and for each building.

## Check the result
- [ ] The parti fits in one sentence.
- [ ] Each test cites a drawing or passage.
- [ ] Breaks are reported, not hidden.

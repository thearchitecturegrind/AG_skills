Check a ramp's slope, rise per run, landings, width, handrails, and edge protection. Input: $ARGUMENTS
If $ARGUMENTS is empty, ask for: total rise, run lengths, landing sizes, width between handrails, handrail heights, and the accessibility standard text.
Use only table values or code text the user pastes, or ones you fetch from a current official source and cite with URL and date; never use values from memory. If you cannot verify a value, label it unverified.
Steps:
1. compute the slope as rise divided by run for each run, and as a ratio
2. check the maximum rise per run and the maximum total, if any
3. check landing dimensions at top, bottom, and turns
4. check clear width, handrail height and extensions, and edge protection
5. compare each with the sourced limit
Show every calculation line by line so the reviewer can follow it.
Result: pass, fail, marginal, or cannot-tell for each element, with the numbers behind it, the source of each limit, and any missing input.
This is a review aid for a licensed professional, not a compliance determination.

# Design Addition
Produces a structured plan for the connection between old and new, with the questions that must be answered about the existing building. A good result chooses a junction strategy and lists what must be verified on site.

## Ask first
1. What is the existing building (age, construction, condition) and do you have drawings or a survey? [if not, every existing fact is "assumed" and needs verification]
2. What is the addition for, and roughly how big? [ask for the programme]
3. Is the existing building protected (listed, heritage) or constrained by planning? [if yes, supply the rules; I will not recall them]

## Core rules
- Decide the relationship first (continue, contrast, or link) because every junction detail follows from it.
- Treat existing information as unverified until measured; old buildings differ from their drawings.
- Match levels at thresholds and check floor build-ups, since small steps become accessibility and detailing problems.
- Plan the junction for movement, water, thermal break, and fire separation; the licensed professional confirms the last item.
- Check the existing structure's capacity before attaching or removing anything; flag for a structural engineer.

## Workflow
1. Summarize the existing building and what is unknown.
2. Choose and justify the relationship (extend, contrast, or link).
3. Set levels, openings in the existing wall, and the position of the junction.
4. List technical interfaces: structure, roof and wall tie-in, services, drainage, access.
5. List surveys and consents needed before design is fixed.
6. Output: Existing summary, Strategy, Junction table (element, proposal, what to verify), Risks, Survey and consent list.

## If your setup is different
- Vertical addition: add load path and access during works.
- Heritage setting: lead with significance and reversibility, using the authority's own guidance.
- No drawings at all: produce a survey checklist before any design proposal.

## Check the result
- [ ] Existing conditions are marked as verified or assumed.
- [ ] Each interface lists what must be checked.
- [ ] Structure and fire are flagged, not decided.

# Circulation Study
Maps the routes people and goods take and shows where they collide or double back. A good result lists each route, the points where routes meet, and which meetings matter.

## Ask first
1. Which user groups move through the building (public, staff, patients, deliveries, waste)? [list them; ask if unsure]
2. Which plan sheets do you have, and which entries and exits exist? [if only part of the plan, limit the study to it]
3. Which routes must stay separate (clean and dirty, public and private)? [if unknown, infer and label]

## Core rules
- Trace routes from real origins to real destinations; a route that ignores where people actually start is decoration.
- Rank conflicts by how many people and how often, then by consequence; a rare crossing of public and secure flows can matter most.
- Count travel distances from the drawing only if a scale is given, and show the numbers.
- Look at dead ends, narrow points, and door swings, since these create bottlenecks.
- Escape routes and accessible routes are reviewed by the licensed professional against the governing code; this study only flags concerns.

## Workflow
1. List the groups and their start and end points.
2. Trace each route room by room, noting doors, stairs, and lifts.
3. Overlay routes and mark crossings, shared segments, and bottlenecks.
4. Score each conflict for frequency and consequence.
5. Suggest fixes: reposition a door, add a link, separate in time, or accept.
6. Output: Route list, Conflict table (location, groups, why it matters, fix), and a one-line verdict per route group.

## If your setup is different
- Multi-storey building: add vertical circulation capacity and where routes change level.
- No scale: compare routes by number of turns and doors rather than distance.
- Existing building: ask for observed behaviour, which beats the drawn route.

## Check the result
- [ ] Each route runs from a stated origin to a stated destination.
- [ ] Conflicts cite a location on the plan.
- [ ] Egress is flagged, not assessed.

Write a product paragraph for a specification section using $ARGUMENTS.
If $ARGUMENTS is empty, ask for the product type, performance requirements, standards the user wants, section number, and whether the firm has a master spec format.

2. Use performance language, and name manufacturers only if the user supplies them.
3. For standards, test methods, or values, use only what the user provides or what you verified from an official source; otherwise leave [standard] and mark unverified.
4. Tie it to Part 1 submittals and Part 3 installation notes by listing items to add elsewhere.
Rules: no invented values. Content on fire, structure, or accessibility requires review by the responsible professional.
Output: the paragraph, a list of placeholders, and companion paragraphs to check.

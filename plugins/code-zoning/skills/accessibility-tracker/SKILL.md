# Accessibility Tracker
Produces a living checklist of accessibility items for a project, each tied to a source, a drawing location, and a status. A good result shows at a glance what is verified, what is open, and who owns it.
## Ask first
1. Which accessibility standards apply here (federal, state, local, or the owner's own)? If unsure I will find the adopted ones from official sources. [find them]
2. Project type, use, and whether it is new work or an alteration. [required]
3. Do you already have a checklist or a prior review to build from? [start fresh]
## Core rules
- Organize by area (route, entrance, restroom, parking, and so on) because reviewers and consultants work that way.
- Every line needs a source citation that you or the user verified; I do not write clearance values from memory.
- Track status as open, designed, verified on drawings, or not applicable with a reason; 'not applicable' without a reason gets challenged.
- Keep it in one table so changes are dated and visible.
- This is a tracking aid for a licensed professional, not an accessibility determination.
## Workflow
1. Confirm the applicable standards and editions; list them at the top.
2. Generate the area headings relevant to the building type and ask which are in scope.
3. For each line, record the requirement topic, source citation, drawing reference, owner, and status. Leave limits blank unless the user supplies the text.
4. Add variance or technical-infeasibility notes where claimed, with the documentation needed.
5. Output: a table (Area | Item | Source | Sheet | Status | Owner | Date) plus a short open-items list.
## If your setup is different
- Several standards apply: add a source column per standard and note the stricter.
- Existing building: add a column for path-of-travel and cost-threshold rules where the user supplies them.
- Outside the US: swap in the local accessibility regulation and verify it officially.
## Check the result
- [ ] No limit appears without a supplied or verified source.
- [ ] Not-applicable lines carry reasons.
- [ ] Every open item has an owner.

# Change Order Review
Produces a review of a change order's scope, price build-up, time impact, and release language. A good result tells the signer exactly what is being agreed and what is being waived.
## Ask first
1. Do you have the change order and the contractor's backup (quotes, labor, markups)? [ask]
2. Which contract governs change terms (and its markup limits)? [ask; do not assume]
3. Was a directive or RFI response issued first? [ask]
## Core rules
- Compare the change to the original documents; scope already in the contract is not a change.
- Check math and markups against the contract's stated rates; never against remembered norms.
- Read release language; 'full and final' wording can waive later claims.
- Signing commits the firm and owner; flag for a licensed professional and counsel.
## Workflow
1. Identify the cause (owner request, design error, field condition) and the document it traces to.
2. Check the description of work for clear boundaries.
3. Break down the price: labor, material, subcontractor, overhead, profit, bond; check arithmetic.
4. Compare markups to the contract limits the user supplies.
5. Review time: days requested, schedule basis, concurrent delay, and any reservation of rights.
6. Output: summary, price table with checks, issues list, questions to ask before signing, and a recommendation to seek review.
## If your setup is different
- If there is no backup data, say the price cannot be tested and request it.
- If it is a no-cost time extension, focus on schedule logic and release language.
- If the contract is unavailable, list the clauses you would need rather than assuming.
## Check the result
- [ ] Arithmetic is shown step by step.
- [ ] Release and waiver wording is quoted.
- [ ] The result states it is a review aid, not approval to sign.

# Elevation Review
Reads an elevation drawing as a set of decisions and a set of omissions. A good result says what the facade commits to, what it quietly leaves open, and where it disagrees with the plan.

## Ask first
1. Which elevation, and do you have the matching plan and section? [if not, say the review cannot check consistency]
2. What should the facade express (civic, domestic, quiet, active)? [if unstated, infer and label it]
3. Is the drawing at concept or documentation level? [concept: judge composition; documentation: also check notes and dimensions]

## Core rules
- Judge the elevation against the plan behind it; a window with no room, or a room with no window, is the commonest error.
- Distinguish what the drawing decides (opening sizes, material break lines) from what it hides (depth, shadow, reveals, what sits behind glass).
- Check ground and sky lines: where the building meets earth and roof are where elevations most often go vague.
- Elevations flatten depth, so ask for a section or model view before judging projections or overhangs.
- Safety items such as guards, egress openings, and glazing safety are flagged for the licensed professional only.

## Workflow
1. List the visible decisions: bays, rhythm, openings, materials, levels, roof edge.
2. List what is hidden or undecided: depths, joints, drainage, signage, services visible on the facade.
3. Cross-check each opening and level against the plan and section; record mismatches with sheet references.
4. Assess composition against the stated expression.
5. Output: Decisions, Hidden or open, Mismatches (with sheet refs), Composition notes, Questions for the designer.

## If your setup is different
- Only an image of an elevation: no dimensions can be trusted; treat proportions as approximate.
- Multiple elevations: review one fully, then list only cross-elevation conflicts for the rest.
- Different drawing convention (for example survey elevations): ask what is measured versus drawn.

## Check the result
- [ ] Each mismatch names both sheets it compares.
- [ ] Hidden items are listed, not guessed at.
- [ ] No compliance statement is made.

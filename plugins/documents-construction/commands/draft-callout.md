---
Write the text for a drawing callout about $ARGUMENTS.
If $ARGUMENTS is empty, ask what the callout points to, the materials and layers, and the scale and sheet.
1. Use short, imperative, technical wording with no filler.
2. Order layers from exterior to interior (or top to bottom) in a consistent way.
3. Name materials by generic description; add product names only if the user gives them.
4. Reference spec sections only if supplied; otherwise leave a placeholder.
5. Give two variants: concise and full.
Rules: do not invent dimensions, ratings, or thicknesses; use placeholders such as [size]. Note that the licensed designer must confirm the content.
Output: the callout text, plus open items to confirm.

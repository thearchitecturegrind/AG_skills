# Option Compare
Produces a comparison table of two to five design options, with evidence for each cell and a clear statement of what the choice trades off. A good result helps a client decide without hiding the weighting.

## Ask first
1. What are the options, and what do you have on each (areas, drawings, cost, notes)? [if a value is missing, mark "unknown", never estimate silently]
2. Which criteria does the decision-maker care about, in order? [if unknown, propose five and ask to confirm]
3. Who decides, and is anything already ruled out (budget cap, site limit)? [assume no hard limits]

## Core rules
- Fix the criteria before looking at which option wins; choosing criteria afterwards bends the result.
- Use the same unit and basis for every option, or the table compares different things.
- Mark each cell with its source (drawing, user number, judgement); judgement cells are labelled as such.
- Show trade-offs, not a single score; weighted totals look objective but hide the weights.
- If a weighting is used, show the weights so the client can change them.

## Workflow
1. Normalize option names and list the facts supplied for each.
2. Agree the criteria and their order of importance.
3. Fill the table; mark unknowns and judgements.
4. Identify dealbreakers (options failing a hard limit) and remove or flag them.
5. Write what each option does best, what it gives up, and what would change the ranking.
6. Output: comparison table, trade-off sentences per option, unknowns that could flip the result, and a suggested question for the decision-maker.

## If your setup is different
- Only qualitative information: use a simple better/similar/worse scale against the first option.
- Costs involved: use supplied or locally sourced figures only, and label the date and basis.
- One option is an existing building: include the do-nothing baseline as a column.

## Check the result
- [ ] Every cell has a source or the word unknown.
- [ ] Weights, if any, are visible.
- [ ] The result says what could change the ranking.

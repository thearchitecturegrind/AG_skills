# Set Reader
Produces a classification of a drawing set with the evidence for it and what the phase implies. A good result says how complete the set is and what to expect from it.
## Ask first
1. Do you know the project phase or purpose? [infer, then confirm]
2. What do you plan to do with it (price, permit, build)? [ask]
3. Is a sheet index available? If not, build one from title blocks.
## Core rules
- Base the classification on evidence (titles, stamps, dates, level of detail), not on a guess.
- Several sets can look alike; give a confidence level and the alternative.
- Phase names vary by firm and contract, so use the document's own words.
- A stamp or 'for construction' label is a fact to report, not a legal approval.
## Workflow
1. Read the title block, issue date, revision block, and any 'issued for' label.
2. Check for professional seals or signatures, and note whether they appear.
3. Judge detail level: single-line plans vs fully dimensioned, schedules, details, specifications.
4. Check for missing disciplines (structural, mechanical, electrical, plumbing, civil).
5. State the likely type, evidence, confidence, and what is probably still missing.
6. Output: classification, evidence table (sheet, observation), and suggested next steps.
## If your setup is different
- If labels disagree with content, report the conflict and ask the owner or architect.
- If it is a mixed set, classify by discipline.
- If the set is partial, say which sheets would confirm the type.

- [ ] Evidence cites sheets.
- [ ] Confidence level and alternatives are stated.
- [ ] Missing disciplines are listed.

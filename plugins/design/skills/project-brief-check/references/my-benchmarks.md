# My Benchmarks

Planning-grade figures for sanity checks only — they flag an implausible brief, they don't estimate anything. The skill uses only what's here; if a building type isn't listed, it skips the check and says so.

**Status:** figures marked *unverified* were collected secondhand and have not been checked against a primary source. Replace or confirm them with your own project data, cost consultant, or current RSMeans before relying on them, and update the source column.

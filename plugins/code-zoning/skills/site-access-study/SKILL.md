# Site Access Study
Produces a short study of access routes for general vehicles, delivery and service vehicles, and emergency apparatus, with dimensions needed and conflicts found. A good result states what each route requires and whether the site provides it.
## Ask first
1. Site plan or survey, plus adjacent street information. [required]
2. Which vehicles matter: delivery, waste, fire, and any special trucks? [ask]
3. Local access standards for fire and driveways, pasted, or I will find them from official sources. [find]
## Core rules
- Define the design vehicle first, since access is meaningless without it.
- Take dimensional requirements from the authority's text; do not use remembered numbers.
- Test the route in sequence: street, entrance, turning, route to building, staging position.
- Check overhead and below-grade obstacles, which plans often leave out.
- Fire access conclusions need confirmation from the fire authority; this is a planning aid.
## Workflow
1. List vehicles and their dimensions (from the user or data sheets).
2. Trace each route from the street onto the site and to key points.
3. Compare available widths, radii, clearances, and grades with the sourced requirements.
4. List conflicts and options for resolving them.
5. Output: Vehicle | Route | Requirement (source) | Provided | Conflict | Option.
## If your setup is different
- Landlocked or tight site: focus on easements and neighbor agreements.
- Urban site: add curb, sidewalk, and loading zone considerations.
- Rural site: add road surface and bridge load questions for the authority.
## Check the result
- [ ] Each vehicle has a route.
- [ ] Requirements are sourced.
- [ ] Conflicts have options.

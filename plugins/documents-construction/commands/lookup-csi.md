---
description: Finds the specification section number for a product or scope.
argument-hint: [product or scope, e.g. fluid-applied air barrier]
---
Find the specification section number for $ARGUMENTS.
If $ARGUMENTS is empty, ask for the product or scope and which numbering edition the firm uses.
1. Look up the number and title in the current MasterFormat listing (or the edition the user names) from an official or publisher source. Never give a number from memory.
2. Report the 6-digit number, title, division, and the source and edition.
3. Give one or two nearby sections that might fit better, with how to choose.
4. If you cannot reach a source, say 'unverified' and ask the user to paste the listing.
Rules: titles change between editions; state which one you used.
Output: a short table (number, title, division, edition, source) and a one-line choice note.

# Spec Outline Builder
Produces a list of spec sections, grouped by division, with the drawing items that drive each. A good result is complete enough for the spec writer to start and cites sheets.
## Ask first
1. Which drawings are available? [ask for the set or schedules]
2. Which numbering format does the firm use (MasterFormat edition)? [ask; look up the current listing]
3. Is the project small or commercial? [ask; it changes the list]
## Core rules
- Section titles and numbers must come from the current MasterFormat listing or the firm's template, not memory.
- Every drawn material or system should map to a section or be listed as unmapped.
- Include general requirements even though they are not drawn.
- Mark sections you suspect but cannot confirm from the drawings.
## Workflow
1. Read the drawings for materials, products, systems, and notes.
2. List each item with its sheet reference.
3. Look up matching section numbers from the current listing; note the edition used.
4. Group by division and add general requirements.
5. Mark unmapped items and questions.
6. Output: table (division, section number and title, driver item, sheet, confidence).
## If your setup is different
- If the firm has a master spec, map to its sections instead.
- If the numbering listing cannot be accessed, leave numbers blank and mark unverified.
- If the project uses another format, ask for the format.
## Check the result
- [ ] Numbers come from a named source.
- [ ] Every section has a sheet driver or is marked general.
- [ ] Unmapped items are listed.

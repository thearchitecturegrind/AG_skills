# Jurisdiction Profile
Produces a dated profile of the jurisdiction: adopted codes and editions, local amendments, zoning contact points, submittal rules, and review processes, each with a source URL. A good result is reusable and clear about what is unverified.
## Ask first
1. Which jurisdiction (city, county, state)? [required]
2. Which topics matter: building, fire, energy, accessibility, zoning, or all? [all]
3. Do you have a prior profile to update? [new]
## Core rules
- Use the jurisdiction's official site or code publisher; secondary summaries go stale.
- Record the date checked on every row because adoption changes.
- Distinguish adopted code, local amendment, and local policy; people treat them as one.
- Mark anything that could not be confirmed as unverified, not blank.
- Do not list contacts or phone numbers unless the official page shows them.
## Workflow
1. Find the adopting ordinances and the editions they adopt.
2. Locate the local amendments and note the sections amended.
3. Collect submittal requirements, review types, and fee or timeline pages.
4. Record where interpretations are published and who issues them (by role).
5. Output: table (Topic | Adopted item | Edition | Local amendment | Source | Date checked | Status).
## If your setup is different
- Multiple authorities overlap (state, county, city): add a column for who has authority over which topic.
- Updating a profile: show what changed since the earlier date.
- Outside the US: keep the structure and swap in the national and local instruments.
## Check the result
- [ ] Each row has a URL and date.
- [ ] Unverified items are marked.
- [ ] Amendments are separate from base code.

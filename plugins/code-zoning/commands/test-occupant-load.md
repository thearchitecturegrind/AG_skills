Check occupant load for a space from a known table row. Input: $ARGUMENTS
If $ARGUMENTS is empty, ask for: the use row and load factor (or paste the table), the area, and whether the area is gross or net per the table.
Use only table values or code text the user pastes, or ones you fetch from a current official source and cite with URL and date; never use values from memory. If you cannot verify a value, label it unverified.
Steps:
1. state the factor and its basis
2. confirm the area basis matches
3. divide area by factor, showing the number
4. apply rounding per the text
5. add any fixed seating or special counts
Show every calculation line by line so the reviewer can follow it.
Result: the occupant load with the numbers, or cannot-tell if the basis mismatches, with the numbers behind it, the source of each limit, and any missing input.
This is a review aid for a licensed professional, not a compliance determination.

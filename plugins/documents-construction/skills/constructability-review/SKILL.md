# Constructability Review
Produces a list of buildability concerns tied to specific sheets and spec sections, with suggested questions. A good result helps the design team fix issues before bidding.
## Ask first
1. What stage and which documents are included? [ask for list]
2. Is it new construction, renovation, or a tight site? [ask; renovation changes the questions]
3. Any known constraints (occupied building, crane access, schedule)? [ask]
## Core rules
- Cite the sheet or section for every concern, so the designer can respond.
- Frame as a question or risk, since the designer may have intent you cannot see.
- Separate 'cannot be built as drawn' from 'harder or costlier than expected'.
- Structural, fire, and life-safety observations go to the licensed engineer or architect for decision.
## Workflow
1. Skim the set for sequencing: what must come first and what blocks what.
2. Check details for tolerances, clearances, access for installation, and conflicting materials.
3. Check that drawings and spec agree on products and methods.
4. Look for missing details at transitions, penetrations, and edges.
5. Rate each issue: critical, important, or minor.
6. Output: table (sheet or section, issue, why it matters, suggested question, severity).
## If your setup is different
- For renovation, ask what existing conditions have been verified.
- If only partial sets are provided, review only that scope and name the gaps.
- If a trade is outside your knowledge, mark the item for a specialist.
## Check the result
- [ ] Every issue cites a location.
- [ ] Each issue explains the effect on building it.
- [ ] Life-safety items are routed to licensed professionals.

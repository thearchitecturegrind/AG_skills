# Plan Check Response Builder
Produces a response matrix: each comment quoted, the response, the revised sheet and detail, and the status. A good result lets the reviewer verify each answer in under a minute.
## Ask first
1. Paste the comment list, with any codes the reviewer cites. [required]
2. Which sheets changed in the resubmittal? [unknown; I will leave placeholders]
3. Does the authority supply a response form? [use my table]
## Core rules
- Quote each comment verbatim; a paraphrase can change the question being answered.
- Respond to what was asked and point to where the change lives, since reviewers look for the cloud.
- Do not claim a change was made unless the user confirmed it; unknown becomes a placeholder.
- Verify any code citation from the reviewer or from us before restating it; otherwise mark unverified.
- Disagreements are polite, cite the source, and escalate to the licensed professional of record.
## Workflow
1. Number and quote the comments.
2. Group by discipline and mark which team member owns each.
3. Draft a response that states the action, location, and any calculation.
4. Mark status: revised, clarified, disagree, or pending information.
5. Output: Comment no. | Quote | Response | Sheet/detail | Owner | Status.
## If your setup is different
- Comment is ambiguous: draft a clarifying question rather than a guess.
- Authority requires its own form: map columns to its fields.
- Comment cites an outdated section: note the discrepancy neutrally with the verified source.
## Check the result
- [ ] Every comment has a response or a question.
- [ ] Revisions point to sheet locations.
- [ ] No claims of changes not confirmed.

---
description: Writes a field observation report with photos from notes.
argument-hint: [paste your notes and list or attach photos with locations]
---
Write a site visit report from $ARGUMENTS.
If $ARGUMENTS is empty, ask for date, project, attendees, weather, notes, and photos with locations. Use placeholders for anything missing; never invent observations.
1. Header: project, date, time, weather, attendees, purpose.
2. Work in progress by area, using the user's facts.
3. For each photo: number, location, one factual caption. Describe only what is visible.
4. Observations separated from instructions; list items needing action with who and by when (as the user gave).
5. Open questions and items not observed.
Rules: report observations, not conclusions about code or structure. Say the report is for review by the responsible professional before issue. Do not state approval or acceptance of work.
Output: report text ready to paste, photo table, and an action list.

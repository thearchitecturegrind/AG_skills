# Drawing Diff
Produces a sheet-by-sheet list of changes between two drawing revisions, noting which were clouded or listed in the revision block. A good result tells the team what to reprice, rebuild, or re-coordinate.
## Ask first
1. Which is the earlier and which is the later issue, and their dates? [ask]
2. Do you have a revision list or bulletin describing changes? [ask for it]
3. Whole set or specific sheets? [whole set]
## Core rules
- Point to sheet and grid or area for each change so it can be found.
- Compare drawn content, not only clouds; clouds are often missed or left off.
- Describe changes factually (moved, resized, added, deleted), then give impact.
- Do not estimate cost; flag items for the estimator or contractor.
## Workflow
1. Match sheets between issues by number and title; list sheets added or removed.
2. Check revision blocks and clouds on each sheet.
3. Compare views visually: dimensions, tags, notes, schedules, details. Use page images at similar zoom.
4. Record each change with sheet, location, before, after.
5. Mark each as clouded, listed, or unflagged.
6. Output: a table by sheet (location, change, flagged?, who may be affected) and a list of unflagged items.
## If your setup is different
- If sheets are scanned or shifted, align by a known feature like a grid line and say so.
- If only one revision exists, say you cannot compare and offer Drawing Reader.
- If sheet numbers changed, match by title and content and state the mapping.
## Check the result
- [ ] Each change names a sheet and location.
- [ ] Unclouded changes are listed apart from clouded ones.
- [ ] Cost and structural effects are flagged for professionals, not decided.

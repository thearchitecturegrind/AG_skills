Check stair geometry against the supplied code text. Input: $ARGUMENTS
If $ARGUMENTS is empty, ask for: stair type, number of risers, riser height, tread depth, width, landing sizes, headroom, handrail data, and the code text.
Use only table values or code text the user pastes, or ones you fetch from a current official source and cite with URL and date; never use values from memory. If you cannot verify a value, label it unverified.
Steps:
1. verify total rise equals risers times riser height
2. check riser and tread against limits and the allowed variation
3. check width, landings, headroom, and handrails
4. state the margin for each
5. flag unusual elements such as winders or open risers for text
Show every calculation line by line so the reviewer can follow it.
Result: pass, fail, marginal, or cannot-tell for each element, with the numbers behind it, the source of each limit, and any missing input.
This is a review aid for a licensed professional, not a compliance determination.

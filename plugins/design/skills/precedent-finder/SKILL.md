# Precedent Finder
Produces a short, honest list of built or well-documented projects that address a given design condition, with what to learn from each. A good result is verifiable, varied, and clear about why each case is relevant.

## Ask first
1. What is the condition or concept (for example a narrow urban plot, a courtyard school, passive cooling)? [no default; ask]
2. What scale, climate, and building type do you need to match? [any, but say the mismatch for each]
3. Do you want famous works or lesser-known, and can I search the web? [mix; if no search, label everything "from memory, unverified"]

## Core rules
- Verify each project against a reliable source (architect's site, publication, museum) before listing it; memory alone can misattribute buildings.
- Give name, architect, location, and year only when a source confirms them; otherwise write "unverified".
- State what the precedent does that is relevant, in one sentence, and where it differs from the user's case.
- Cover different strategies, not five near-copies; variety teaches more.
- Never invent a project or quote; a missing example is better than a false one.

## Workflow
1. Restate the condition in one sentence and list its sub-issues.
2. Search for candidates; collect three to six per sub-issue.
3. Verify each with a source and note the link or citation.
4. Extract the lesson: plan, section, material, or process move.
5. Group by strategy and flag mismatches of climate, scale, or budget.
6. Output: a table of Project, Architect and place (verified or unverified), Strategy, Lesson, Difference from your case, Source.

## If your setup is different
- No web access: give strategies and search terms, plus a clearly marked unverified candidate list.
- Student use: add what to look for in the plans and sections.
- Local-context request: favour projects in similar climate and regulation, and say so.

## Check the result
- [ ] Every project has a source or the word unverified.
- [ ] The list covers at least two different strategies.
- [ ] Each lesson is specific, not "nice use of light".

# Design Partition
Defines the layers of an interior wall and where it stops at top and bottom, based on what the wall must do. A good result names the performance requirements, the build-up, and the head and base conditions.

## Ask first
1. What must the wall do: privacy, sound, fire separation, moisture, support for fixtures? [list each; ask for targets]
2. What is the structure above and below (slab, deck, suspended ceiling), and the clear height? [if unknown, mark assumed]
3. Which ratings or tests are required, and from which source? [supply the code section or specification; I will not quote ratings from memory]

## Core rules
- Start from performance; thickness follows requirements, not habit.
- Decide where the wall ends: stopping at the ceiling lets sound and smoke pass over, so rated or acoustic walls usually run to the structure above.
- Detail the head with allowance for deflection and movement, and the base with moisture protection.
- Use tested assemblies from manufacturer or test listings; changing one layer can void a rating.
- Fire and acoustic ratings are for the licensed professional to confirm; this skill proposes, it does not certify.

## Workflow
1. List requirements with their sources.
2. Propose the build-up from one face to the other: boards, studs, insulation, cavity, with thicknesses.
3. Total the thickness and show the sum, since it affects room sizes.
4. Define head, base, and junctions: deck, ceiling grid, corners, abutment to façade, door frames.
5. Mark penetrations and how they are sealed.
6. Output: build-up table, thickness sum, head and base notes, requirement-to-solution matrix, items to verify against a tested assembly.

## If your setup is different
- Timber or masonry wall in a heritage building: ask what is existing and check compatibility.
- Demountable or glass partition: swap the build-up for system data supplied by the maker.
- Different codes or units: use the user's references and one unit.

## Check the result
- [ ] Each requirement maps to a layer or detail.
- [ ] The head condition is stated.
- [ ] Ratings are marked as needing confirmation.

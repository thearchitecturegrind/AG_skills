Check provided open space against the district's open space requirement. Input: $ARGUMENTS
If $ARGUMENTS is empty, ask for: lot area, required open space rule (percentage, per-unit, or other), the definition of qualifying open space, and the areas you provide.
Use only table values or code text the user pastes, or ones you fetch from a current official source and cite with URL and date; never use values from memory. If you cannot verify a value, label it unverified.
Steps:
1. compute the requirement from the rule, showing the arithmetic
2. list each provided area and whether it qualifies under the definition, with reasons
3. subtract any disqualified or double-counted areas
4. total the qualifying area and compare
5. note minimum dimensions or access conditions the definition imposes
Show every calculation line by line so the reviewer can follow it.
Result: pass, fail, marginal, or cannot-tell, with the numbers behind it, the source of each limit, and any missing input.
This is a review aid for a licensed professional, not a compliance determination.

# Estimate Fee

Build a fee from the work, show the math, and make assumptions visible so the number can be defended and adjusted.

## Ask first
1. Project type, size, and rough construction budget if known.
2. Services included (phases, consultants, CA, extras) and anything excluded.
3. Fee method preference: hourly, fixed, percentage of construction cost, or a mix? [default: build bottom-up by hours, then compare]
4. Your billing rates (or typical ranges) and target overhead/profit multiplier.

## Core rules
- Hours-by-phase and role is the primary method; use percentage-of-cost only as a cross-check, since typical percentages vary widely and you shouldn't present one as a standard.
- Every number is an assumption the user can edit. Label inputs clearly.
- Include contingency for unknowns and say what it covers.
- State exclusions plainly (reimbursables, consultants, revisions beyond a number of rounds).

## Workflow
1. Break the scope into phases and tasks.
2. Estimate hours per task by role.
3. Multiply by rates, add consultants and reimbursables, apply multiplier and contingency.
4. Cross-check with a percentage-of-cost range and note any gap.
5. Present the fee, an assumptions list, exclusions, and two alternative structures.

## If your setup is different
- No rates: use placeholders marked "replace with yours".
- Spreadsheet wanted: build the content first, then use the xlsx skill.

## Check the result
- Math adds up and totals are reproduced.
- Assumptions and exclusions are written down.
- The fee is shown with a range, not a single false-precision number.
